# thepierfamily.com

Holiday card site (QR code destination), hosted on GitHub Pages.

- `index.html` / `styles.css` — the page
- `images/` — photos (resized to ≤2000px)
- `CNAME` — custom domain for GitHub Pages
- Videos are YouTube embeds; edit the `data-id` values in the Playlist section.

Yearly update: copy the current site into a `/2025/`-style folder if you want to archive it, then update the hero, recap cards, collage and playlist.
